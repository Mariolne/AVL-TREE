# C++ AVL Tree Implementation

这是我用 C++ 从零手写的一个平衡二叉搜索树（AVL树）项目。主要目的是为了加深对数据结构底层指针操作的理解，顺便把课本上的理论代码真正落地。

## ✨ 核心功能
- **基础的增删查**：实现了插入、删除、查找，最坏时间复杂度能稳定在 O(log N)，不会像普通二叉搜索树那样退化成链表。
- **四种旋转**：完整实现了 LL、RR、LR、RL 四种情况的旋转逻辑，并在代码中做了注释。
- **内存管理**：写了析构函数，测试过用大几百个数据反复插入删除，用调试工具看没有内存泄漏。
- **交互测试**：写了一个简单的终端菜单，可以直接输入数字测试树的动态变化。

## 🧠 开发过程中的小演进与踩坑记录

写这个项目的时候踩了不少坑，代码也是改了好几版才稳定下来：

1. **关于旋转的传参**：
   - **初版**：因为旋转后根节点会变，我一开始是传 `tree* t`，然后写了一个 `find_parent` 函数去全局找父节点来重新连接。后来发现这样每次旋转都要重新从根节点往下找一次，效率太低。
   - **改进**：后来查阅资料，改成了 C++ 的指针引用（`tree*& t`），利用递归回溯的特性，直接修改指针本身。这样代码不仅短了一大截，效率也高了很多。

2. **删除节点时的指针 Bug**：
   - 删节点是最折磨人的。如果删的节点有两个子节点，找右子树的最小值替换时，我一开始是用对象赋值 `*t = *tmp`，结果调试时发现指针全乱了，还会造成双重释放导致程序崩溃。
   - **解决**：后来改成了指针转移 `t = tmp`，先存下旧指针，转移后再 `delete` 旧指针，彻底解决了这个问题。

3. **LR 和 RL 旋转**
   - 一开始写双旋的时候，脑子经常转不过来，左右反了。后来自己画了图，理清了逻辑：LR 就是先对左子树左旋，再对整体右旋。代码里直接用 `LL_rotate(t->l)` 组合调用，瞬间清爽。
